# BL-13.1 — Boolean-only reference and Pareto baseline

## Purpose

BL-13.1 establishes the Boolean-only reference population required before any Boolean × X function can be described as unusual under a matched construction budget.

It contains two linked experiments.

## BL-13.1.1 — exact four-input reference-space calibration

Enumerate all `2^(2^4) = 65,536` scalar Boolean functions on four inputs and analyze every truth table with the pinned SciRust Boolean metrics.

Recorded properties:

- exact algebraic degree;
- exact nonlinearity;
- balancedness;
- bent property;
- correlation-immunity order;
- resilience (`balanced && correlation_immunity > 0`);
- an explicitly operational three-valued plateaued predicate: the Walsh spectrum contains zero and all non-zero coefficients share one absolute magnitude.

This experiment is an exhaustive oracle calibration. It is not a synthesis claim and it does not establish novelty.

### Validation criteria

- exactly 65,536 functions are scanned;
- at least one balanced, bent, resilient and operationally plateaued function is recovered;
- maximum nonlinearity is exactly 6 for four variables;
- repeated executions are deterministic.

## BL-13.1.2 — bounded eight-input Boolean-only search

Generate exactly 4,096 deterministic single-output Boolean circuits using the shared `booleanlab-core::BooleanCircuit` semantics.

Frozen configuration:

- inputs: 8;
- candidates: 4,096;
- gates per candidate: uniformly selected in the inclusive range 4..=24 by the frozen deterministic generator;
- gate grammar: `NOT`, `AND`, `OR`, `XOR`, `XNOR`, `NAND`, `NOR`, `MUX`;
- constants: false and true;
- seed: `0x424c31335f424153`;
- output: final generated gate;
- each candidate is exhaustively evaluated over all 256 inputs;
- exact equality is checked on complete truth tables, with the stable fingerprint used only as a bucket index.

### Pareto objectives

A candidate dominates another only when it is no worse in all of the following and strictly better in at least one:

1. maximize nonlinearity;
2. minimize output imbalance from 128 ones;
3. maximize correlation-immunity order;
4. minimize gate count;
5. minimize circuit depth.

Algebraic degree is recorded as a descriptor, not treated as monotonically better or worse.

## Scientific boundary

BL-13.1.2 is a bounded search baseline, not the full Boolean function space and not proof that a missing function cannot be constructed by Boolean logic. Its role is narrower: provide a reproducible Boolean-only population under a declared evaluation and construction budget for later matched comparisons such as BL-13.2.1.

No novelty claim may be made from BL-13.1 alone.
