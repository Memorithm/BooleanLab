## Bounded exactness check

For all 256 Boolean inputs, the generated `(left * right) * mixer` coordinates were finite and had bit-identical `f32` representations before and after `round()`. The control therefore remained on the declared integer lattice for the complete bounded input domain.

This is evidence only for this frozen construction and bounded domain. It is not a general exactness claim for floating-point sedenion arithmetic.

## Interpretation

The control establishes three concrete facts for this frozen construction:

1. the pinned SciRust sedenion implementation can be isolated behind an optional nightly feature without contaminating BooleanLab's stable toolchain;
2. a bounded Boolean -> sedenion -> predicate pipeline can be evaluated exhaustively while preserving its declared integer-lattice check;
3. the frozen sedenion construction induces sixteen distinct, nonconstant Boolean coordinate functions with a heterogeneous algebraic/spectral profile.

No statement is made about whether these functions are new, optimal, useful for AI, or outside known equivalence classes.
