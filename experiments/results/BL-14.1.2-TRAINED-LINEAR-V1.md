## Learning and frozen search

The eight numerical coefficients were learned from zero by the declared 256
gradient steps on 128 TRAIN examples. TRAIN task MSE went from
`1.31542129516601562e1` to `8.25119138971988240e-4`.

The exact binary64 learned-weight bit patterns were:

```text
[4613942798693176518, 13830560624186569212, 4611684626472561456,
 13839562504337691683, 4602693644765963663, 4605334935946523608,
 13835070467554858637, 4609393326009881943]
```

Frozen predicate addresses (p0 is the least-significant address bit), in feature
order: `[5, 6, 5, 3, 4, 0, 3, 0]`.

Of 256 Boolean truth tables, 48 produced a 4/8 mask. Eight truth-table codes tied
for minimum SEARCH task MSE `2.52945972594999180e0`:
`[40, 42, 44, 46, 168, 170, 172, 174]`.

All eight induce the same retained feature set `{0, 2, 3, 6}` on the observed
predicate rows. This is exactly the global-magnitude mask. Different values on
unobserved predicate addresses remain unidentified: eight tied functions are
not eight different sparse topologies or newly discovered functions.

## Interpretation retained without promotion

The selected Boolean masks tie global magnitude on this pilot and are worse than
the activation-energy baseline on VALIDATION. Activation energy itself had a
slightly worse SEARCH task MSE (`2.62228631299317350e0`) than magnitude, illustrating
why selection and validation must remain separate. Validation did not re-rank the
Boolean selection.

Every tested 4/8 mask has substantially higher task error than the dense model.
No quality-preservation threshold was passed or claimed. This run therefore
provides **no Boolean sparsification superiority** and **no useful end-to-end
efficiency result**. It validates the executed training/selection/freeze/scoring
path and retains an unfavorable competent-baseline comparison.

The next experiment must have a separately declared design: multiple input and
teacher regimes/seeds, nonlinear trained models and measured controller overhead.
Do not retune this v1 protocol using the validation results above. TDI-9.3 may
reuse the methodological boundary, not reinterpret these regression numbers as
dynamic-inference evidence.
