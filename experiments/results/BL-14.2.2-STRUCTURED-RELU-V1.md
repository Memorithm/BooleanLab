## Frozen design

Each of three declared regimes (`isotropic`, `unequal_scale`, `correlated`) uses
four fixed seeds. Per trial there are 128 TRAIN, 64 SEARCH and 64 non-final
VALIDATION examples. Eight fixed ReLU features are used and only the readout is
trained for 512 full-batch steps. All twelve trained models, predicate rows and
SEARCH selections are frozen before constructing VALIDATION.

Every sparse arm retains exactly 4/8 complete nonlinear units. Controls are
magnitude, unit-level 2:4 magnitude, activation energy and four fixed random
masks. Boolean candidates are grouped by the exact retained mask while retaining
all truth tables that induce that mask. Validation never re-ranks a SEARCH
winner.

Across the twelve frozen trials, the Boolean SEARCH winner beats / ties / loses
to global magnitude on VALIDATION in `4 / 7 / 1` trials; against unit-level 2:4
in `4 / 5 / 3`; against activation energy in `3 / 5 / 4`; and against the best
of the four fixed random controls in `7 / 0 / 5`. These are descriptive counts
for this declared synthetic panel, not population estimates.

Dense has lower task MSE than every sparse arm in all twelve trials. Therefore
this panel supplies **no quality-preserving sparsity result**. It also supplies
no evidence that the Boolean controller is uniformly better than the competent
structured or saliency controls.

## Work accounting and interpretation

For each 64-example VALIDATION batch the dense arm reports 2,560 reference
multiplications and 512 ReLUs. Every 4/8 sparse arm reports 1,280 reference
multiplications, 256 ReLUs and 512 mask tests. These counters deliberately
exclude training/search, statistics, predicate construction, checks, scoring,
allocation, metadata, memory traffic and the dense comparison oracle. They are
not elapsed-time, energy, bandwidth, HBM-residency or end-to-end compute
measurements.

The useful outcome is methodological and negative/mixed: the implementation
actually skips rejected nonlinear units before projection/ReLU/readout, preserves
SEARCH/VALIDATION separation, retains all exact Boolean truth-table provenance,
and shows that reducing reference arithmetic by this construction can still
materially degrade task quality. Future BL-14 work must keep this result rather
than retuning v1 from its validation outcomes.

A subsequent experiment may move to a separately preregistered trained workload,
dynamic/relational control or hardware measurement. TDI-9.3 may reuse the
validated carrier/freeze methodology, but these synthetic MSE values are not TDI
trajectory evidence and do not authorize TDI-9.2.
