# BL-13.4.1 — bounded exact tropical predicate search

Status: preregistered Development search. No novelty or superiority claim.

## Question

Within one frozen, exhaustively enumerable four-input max-plus grammar, can exact
tropical predicates induce at least one balanced Boolean function with
nonlinearity at least 4 that is not one of the four BL-13.4.0 control truth
tables?

This is a bounded mechanism/discovery gate. It is not a prior-art, EA/CCZ,
cryptographic, hardware, or matched-circuit-cost claim.

## Frozen search universe

Inputs are exactly four Boolean variables `x_0..x_3`, embedded as exact integers
in `{0,1}`. All arithmetic is checked `i64` and every candidate is evaluated on
all 16 input rows.

A term is the max-plus monomial

```text
c + sum(x_i for i selected by mask)
```

with:

- `c in {-1, 0, 1}`;
- `mask` drawn from the empty mask, the four singleton masks and the six
  two-variable masks;
- therefore exactly 33 possible terms.

A polynomial contains exactly two distinct terms. Terms inside a polynomial are
stored in their deterministic lexicographic `(constant, mask)` order. The
polynomial list is the lexicographically ordered list of all unordered two-term
combinations.

For every unordered pair of distinct polynomials with indices `i < j`, emit two
Boolean candidates:

```text
P_i(x) >  P_j(x)
P_i(x) >= P_j(x)
```

No candidate, coefficient, mask, comparison or threshold may be selected or
modified after observing Boolean metrics. Exact truth-table deduplication is
collision-safe; fingerprints are indexing aids only.

## Preregistered hypotheses and advancement rule

- **H0:** after exact deduplication and exclusion of the four frozen BL-13.4.0
  truth tables, the frozen search contains zero balanced functions with
  nonlinearity >= 4.
- **H1:** after the same exact exclusions, at least one unique function is
  balanced and has nonlinearity >= 4.

Advance the BL-13.4 mechanism programme only if H1 is observed. A pass means only
that this bounded tropical grammar reaches the declared Boolean property gate.
It does not establish that tropical construction is better than Boolean-only
search, that the function is novel, or that it is useful in cryptography,
routing, attention or hardware.

## Required exact evidence

The deterministic report must retain:

- number of syntactic terms, polynomials and predicates evaluated;
- exact unique truth-table count and duplicate count;
- constant/nonconstant and balanced counts;
- maximum observed nonlinearity and algebraic degree;
- count satisfying the H1 property gate;
- for every H1 witness retained in the bounded representative set: exact truth
  table, deterministic fingerprint, ANF coefficients, complete Walsh spectrum,
  algebraic degree, nonlinearity, balancedness and correlation immunity;
- exact equality against the four BL-13.4.0 controls.

The representative witness set is selected deterministically after exhaustive
analysis by sorting eligible unique functions by decreasing nonlinearity,
decreasing correlation immunity, decreasing algebraic degree, then ascending
truth-table bytes and retaining at most 16. This selection affects reporting
only, never the H0/H1 decision.

## Required negative evidence and boundaries

If H0 is retained, the zero-witness result is committed rather than retried with
a changed grammar. Resource or implementation failure is `NOT_ASSESSED`, not H0.

Even if H1 passes:

- a truth table not previously seen in this repository is not a discovery;
- no EA/CCZ equivalence conclusion follows;
- no prior-art conclusion follows;
- no construction-cost advantage follows because the Boolean-only baseline is
  not cost-matched in this stage;
- no hardware/performance/energy conclusion follows;
- no protected or final holdout is opened.

Any stronger claim requires a separately preregistered follow-up with explicit
matched-cost controls, declared equivalence tests and prior-art review.
