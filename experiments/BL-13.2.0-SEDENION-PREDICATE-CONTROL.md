# BL-13.2.0 — Sedenion predicate control

## Stage

Nightly-only implementation/control experiment. This is not BL-13.2.1 and does **not** test novelty.

## Purpose

Validate that BooleanLab can consume SciRust's actual sedenion implementation without making the stable BooleanLab core depend on nightly `portable_simd`.

## Toolchain boundary

SciRust `SedenionSimd` is exposed only through the `portable-simd` feature, which requires nightly Rust. BooleanLab therefore keeps the dependency optional behind `sedenion-experiments` and qualifies it in a separate CI job.

The SciRust dependency is pinned to:

`7178bcfc6800e3277b9f16c3f03c70523b53e2c7`

The nightly qualification toolchain must match SciRust's pinned development toolchain:

`nightly-2026-07-02`

## Mapping

Input space:

`x in F_2^8`.

Each bit is embedded as a bipolar coefficient `-1` or `+1` into two sedenions. BooleanLab then evaluates:

`state(x) = (left(x) * right(x)) * mixer`

where `mixer` is a fixed sedenion with coefficients in `{-1,+1}`.

For each coordinate `j in 0..16`, the Boolean projection is:

`f_j(x) = [state_j(x) > 0]`.

This yields sixteen scalar functions `F_2^8 -> F_2`.

## Exactness boundary

The underlying representation is `f32`; therefore this experiment does not claim general exact floating-point sedenion arithmetic.

For this bounded control only, all inputs and the mixer are small integers. The generator fails closed unless every observed output coefficient is finite and exactly integral in its `f32` representation. Only after that check is the sign predicate admitted into the Boolean-function pipeline.

## Metrics

For every coordinate function, report:

- algebraic degree;
- nonlinearity;
- balancedness;
- bent property;
- correlation immunity;
- deterministic fingerprint.

Also report exact and complement-canonical uniqueness counts.

## Interpretation rule

Any generated functions are control artefacts until stronger equivalence screens and matched Boolean-only baselines are available. A distinctive metric vector or fingerprint is not evidence of novelty.

## Gate

The experiment is valid only if:

1. the ordinary stable BooleanLab CI remains green with the optional feature disabled;
2. the separate pinned-nightly job builds SciRust `portable-simd`;
3. all generated coefficients satisfy the bounded integer-lattice checks;
4. nightly tests and Clippy pass;
5. the campaign runner completes deterministically.

A successful BL-13.2.0 authorizes implementation of the stronger BL-13.2.1 comparison; it does not answer BL-13.2.1.
