# BL-13.3.1 — `GF(2^8)` inversion component functions

## Stage

Implementation / control experiment. This stage does **not** test novelty.

## Question

Can BooleanLab generate, fingerprint, deduplicate and analyse Boolean functions induced by an exact non-Boolean mathematical domain `X`, beginning with finite-field inversion?

## Domain and mapping

Two independently parameterised binary extension fields supplied by pinned SciRust are used:

- `Gf2Field::primitive8()` with modulus `0x11D`;
- `Gf2Field::rijndael8()` with modulus `0x11B`.

For every field element `x`:

- `I(0) = 0`;
- `I(x) = x^-1` for `x != 0`.

For output coordinate `j in 0..8`, BooleanLab constructs the scalar Boolean function

`f_j(x) = bit_j(I(x))`.

Thus each field instance produces eight exact functions `F_2^8 -> F_2`.

## Why this is a control

Finite-field inversion is a known nonlinear mapping. The purpose is to prove that the BL-13 pipeline can consume a mathematically structured `X` domain and recover stable exact Boolean metrics without floating-point thresholds or heuristic discretisation.

No output from this experiment may be labelled novel.

## Frozen expectations

For `Gf2Field::primitive8()`, every one of the eight coordinate functions must satisfy:

- input width: 8;
- algebraic degree: 7;
- nonlinearity: 112;
- balanced: true;
- bent: false.

The eight exact truth tables must be pairwise distinct.

The `rijndael8` family is reported under the same instrumentation. Its measured values are evidence, not hard-coded scientific assumptions in this first revision.

## Equivalence discipline

Two counts are reported:

1. exact truth-table uniqueness;
2. uniqueness after the narrow complement equivalence `f ~ f XOR 1` already implemented by BL-13.

No affine, EA or CCZ equivalence claim is made here.

## Failure conditions

The experiment is invalid if:

- a nonzero element in either bundled SciRust field lacks an inverse;
- a generated table is not Boolean or has the wrong size;
- the primitive8 frozen expectations fail;
- CI fails formatting, tests or Clippy;
- the campaign runner cannot reproduce deterministically.

## Promotion gate

Only after this control is green may BL-13.3 expand to parameter sweeps over finite-field constructions, alternate exact predicates, compositions, or search for Pareto-interesting candidates.
